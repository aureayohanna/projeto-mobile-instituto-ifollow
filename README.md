# Instituto Ifollow - Aplicativo de Adoção

Este é um aplicativo móvel desenvolvido para o Instituto Ifollow, com o objetivo de digitalizar e facilitar o processo de adoção e apadrinhamento de animais. O app oferece uma interface intuitiva para que usuários possam conhecer os animais disponíveis e gerenciar suas informações de perfil.

## Tecnologias Utilizadas

* **Frontend:** Ionic Framework & Angular
* **Backend/Banco de Dados:** Firebase (Authentication & Cloud Firestore)
* **Linguagem:** TypeScript
* **Estilização:** SCSS
* **Plataforma:** Android / Web (Hybrid App)

## Funcionalidades Principais

* **Sistema de Autenticação Completo:** Login via E-mail, Google e suporte a login por CPF.
* **Cadastro de Usuários:** Coleta de dados detalhados para validação de adotantes.
* **Navegação por Tabs:** Interface organizada em abas para fácil acesso às diferentes seções do app.
* **Gestão de Adoções:** Controle de animais adotados vinculado ao perfil do usuário no Firestore.
* **Acesso Anônimo:** Possibilidade de navegar pelo app antes de criar uma conta.

## Como rodar o projeto

1. Clone o repositório: `git clone https://github.com/aureayohanna/projeto-mobile-instituto-ifollow.git`
2. Instale as dependências: `npm install`
3. Inicie o servidor de desenvolvimento: `ionic serve`
